# goit-algo-hw-06

Graph construction, visualization, DFS/BFS traversal, and Dijkstra shortest paths.

## Running the examples

Create a Python virtual environment, install `requirements.txt` when present, and run the task file you want to inspect. Most scripts are independent command-line demonstrations.

## What to reuse

Use the individual algorithm implementations, input generators, timing harnesses, and visualization helpers as focused reference examples. Validate assumptions and add tests before production use.
